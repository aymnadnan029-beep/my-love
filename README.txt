موقع رويدا — ضحكة وحب
=====================

ابدأ بفتح index.html في Chrome أو Safari أو Firefox.
الأزرار التفاعلية: ضحّكيني، هات نكتة تانية، ضحكت والله، ورسالة الحب السرية.
يمكن الضغط على القلب الكبير أو إيموجي النكتة لتفعيل تفاعل سريع.

إذا فتحت الموقع داخل معاينة ملفات لا تشغّل JavaScript، نزّل الحزمة وافتح index.html مباشرة في المتصفح.

للحصول على رابط عام، يجب رفع index.html إلى استضافة مواقع ثابتة مثل Netlify أو GitHub Pages. هذه الحزمة غير منشورة على الإنترنت تلقائيًا.
